Это проект веб-приложения по субструктурному поиску химических соединений
Инструкция по запуску:
1. Клонируйте репозиторий git clone https://github.com/Maya-M20/myfirstpyproj.git
2. Перейдите в папку проекта
3. Запустите контейнеры (docker-compose up --build)
4. Откройте в браузере http://localhost:8080/page

В браузерном окне появится страница с поиском молекул 
Попробуйте ввести некоторые соединения в виде SMILES 
Примеры для ввода:
CC
O
C1CCCCC1
CC(=O)O
O=C=O
